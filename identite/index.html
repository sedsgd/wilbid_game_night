Ndop Nuit l'emporte sur les trois critères qui comptent

Les illustrations : oui, mais en système

Plutôt que des scènes dessinées une à une, je propose un emblème par jeu, tous construits sur la même grille de losanges ndop : un panier pour le Marché de Mokolo, des poings pour le Njangi, le pont pour le Wouri, le masque pour les Feymen, le trône pour la finale. Ils servent à la fois de couverture de livret, d'icône sur le site et de dos de carte. Je peux les dessiner en vecteur, donc nets à toutes les tailles et gratuits.

Les tendances qu'on exploite

  • Texture imprimée façon risographie : grain, aplats en deux encres, léger décalage.
  • Typo display très large et serrée, avec des chiffres énormes pour les scores.
  • Motion discret sur le site : le motif ndop se trace quand une page s'ouvre, et le classement monte en direct.
  • Mode nuit par défaut sur le site, puisque tout le monde le consultera dans une salle sombre.
